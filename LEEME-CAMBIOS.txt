CAMBIOS DE ESTA COPIA DE FOLIO
==============================

La app ahora admite agregar TXT, PDF, Markdown (.md), HTML (.html/.htm), imágenes PNG/JPG/JPEG/WebP/GIF y ZIP con esos tipos de archivo.

IMÁGENES
- Folio conserva y muestra la imagen original.
- En la primera importación se pide confirmar el envío a Google Gemini para reconocer el texto.
- El texto reconocido se usa para la narración de Folio; no se muestra como transcripción mientras se ve la imagen.
- La lectura necesita conexión a internet y una llave de Gemini guardada en el navegador.
- Si iniciaste sesión en Supabase, la imagen y el contenido del documento se sincronizan como los adjuntos existentes.

ZIP
- Para ZIP educativos, Folio importa hasta 100 archivos compatibles: Markdown, texto, HTML e imágenes.
- Markdown y texto se guardan como documentos. En HTML se toma el texto visible, sin ejecutar scripts ni insertar código HTML.
- Las imágenes del ZIP se muestran individualmente y se procesan para lectura con Gemini.
- Los archivos .folio y los ZIP que contienen carpeta.json se importan como carpetas de Folio; las imágenes sin transcripción se reconocen durante la importación.
- Los demás formatos dentro del ZIP se ignoran.

NUEVAS FUNCIONES
- Selecciona varios documentos arrastrando el cursor sobre sus filas. Después arrastra cualquiera de los seleccionados a la carpeta destino; también puedes usar las casillas.
- En «Editar documento», usa «Insertar imagen» para colocar PNG, JPG, WebP o GIF en la posición del cursor. Se conserva dentro del texto, se muestra al leer y se incluye en la sincronización y en los respaldos .folio. Máximo 10 MB por imagen.
- También puedes elegir «Usar imagen de Folio» para insertar una copia de cualquier imagen que ya esté guardada como adjunto o dentro de otro documento.
- La vista de imágenes intenta cargar el archivo desde el dispositivo, el respaldo local y la nube; en móvil requiere conexión y sincronización con la misma cuenta para descargar adjuntos que no estén guardados localmente.

INSTALACIÓN
1. Descomprime el ZIP.
2. Sube el contenido de FOLIO-1-main a una rama de prueba o copia local. No reemplaces aún tu versión publicada.
3. Abre la app y prueba primero con una imagen pequeña con texto y un ZIP de prueba.
4. Para publicar, usa el mismo repositorio y la configuración de Supabase que ya tienes. El service worker se actualizó para descargar esta versión.
